## 🎯 Overview

**WhitePaper** is a Django-based notepad web application created with a strong focus on minimalist UI, fast note retrieval, and ergonomic personal knowledge organization.

It provides users with an instant-capture writing environment, tag-based grouping, and full search capabilities across saved documents.

---

## 🚀 Features

* **Distraction-Free Editor**: Clean typography and maximized screen area for uninterrupted drafting and writing.
* **Categorized Notebooks**: Organize thoughts, code snippets, meeting logs, and todo lists into dedicated folders.
* **Full-Text Search**: Fast query filtering across note titles and body content.
* **User Authentication & Privacy**: Isolated user accounts with encrypted credential storage and secure session management.
* **Responsive Layout**: Designed for seamless mobile, tablet, and desktop usage.

---

## 🛠️ Stack & Architecture

* **Backend**: Django 4.x with class-based views and Django ORM models.
* **Database**: SQLite for development / PostgreSQL ready for production.
* **Frontend**: Clean CSS custom styling with mobile-friendly viewport meta controls.
